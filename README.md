## Roadmap Steps

1. **Basic Computer Skills** - Computer skills refer to the knowledge and abilities required to operate computers and related technology. A solid foundation in hardware, software, file systems, and basic troubleshooting is essential before diving into cybersecurity.

2. **Basic Networking Skills** - Networking skills are one of the most important talents to have if you want to be an ethical hacker. Understanding TCP/IP, DNS, HTTP/S, firewalls, and network protocols is fundamental.

3. **Linux Skills** - Linux is the most popular choice for hackers due to its flexibility, open source platform, portability, command line interface, and compatibility with popular security tools. Learn Bash scripting, file permissions, process management, and common Linux distributions like Kali and Parrot OS.

4. **Programming/Scripting Skills** - Programming skills are essential to becoming an effective hacker. One reason you want to know how to code is so you can understand, modify, and write scripts used to test systems. Recommended languages: Python, Bash, PowerShell, and optionally Go or Rust.

5. **PEH by TCM** - In this course, you will learn the practical side of ethical hacking. This course focuses only on tools and topics that will make you successful as an ethical hacker. The course is incredibly **hands on** and covers many foundational topics including Active Directory attacks.

6. **Practice with Vulnerable Labs** - Hands-on practice is critical. Use platforms like [TryHackMe](https://tryhackme.com), [HackTheBox](https://hackthebox.com), and [VulnHub](https://vulnhub.com) to sharpen your skills in realistic environments.

7. **eJPT** - The eLearnSecurity Junior Penetration Tester (eJPT) is a 100% practical certification on penetration testing and information security essentials. By passing the exam, a cybersecurity professional proves to employers they are ready for a rewarding new career.

8. **OSCP** - The Offensive Security Certified Professional (OSCP) certification is the gold standard for penetration testers. This online ethical hacking course is self-paced and introduces penetration testing tools and techniques via hands-on experience. PEN-200 trains not only the skills, but also the mindset required to be a successful penetration tester.

9. **Keep Updating Yourself** - Hacking is a lifelong journey of learning. We must not enter cybersecurity just to hack Wi-Fi passwords or phones. As time goes by, new vulnerabilities are discovered and patched, thus we must stay eager to learn new things. Follow CVEs, attend conferences (DEF CON, Black Hat), and engage with the security community.
